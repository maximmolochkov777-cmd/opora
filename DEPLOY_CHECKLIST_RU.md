# Опора — чек-лист запуска без программиста

## Что уже готово
- код приложения
- экран входа
- AI-чат через серверный route
- SQL-схема базы
- шаблон переменных окружения

## Что нужно сделать тебе

### 1. Создать проект Supabase
- Create new project
- открыть SQL Editor
- вставить `db/schema.sql`
- нажать Run
- скопировать:
  - Project URL
  - anon key

### 2. Создать OpenAI API key
- открыть OpenAI Platform
- создать API key
- сохранить ключ

### 3. Загрузить проект в GitHub
- распаковать архив
- создать новый repo
- загрузить файлы

### 4. Импортировать проект в Vercel
- New Project
- Import Git Repository
- выбрать repo

### 5. Добавить переменные в Vercel
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `OPENAI_API_KEY`
- `APP_BASE_URL`

Для `APP_BASE_URL` после первого деплоя можно поставить адрес Vercel сайта.

### 6. Нажать Deploy
- дождаться публикации
- открыть ссылку сайта

### 7. Проверить 5 вещей
- открывается главная
- работает вход
- работает анонимный вход
- отвечает чат
- открывается кризисный экран на опасные фразы

## Если что-то не работает

### Чат молчит
Проверь `OPENAI_API_KEY` в Vercel.

### База не пишет
Проверь, что `schema.sql` выполнен в Supabase.

### Вход не работает
Проверь auth settings в Supabase.

## Минимум действий
Тебе нужны только:
- Supabase
- OpenAI key
- GitHub
- Vercel

После этого приложение можно открыть в интернете.
